# 简历项目描述

**学生成绩管理小程序 + AI 学情诊断辅助系统**  |  微信小程序 / Flask / SQLAlchemy / MySQL / CloudBase

- 设计并实现管理员、教师、学生、家长四角色 RBAC 与教师班级/课程双重数据范围，覆盖成绩、统计、预警、发布、AI 和留言接口。
- 实现 Excel 预览/确认原子导入、UUID 批次账本和安全撤销，通过前后快照避免覆盖后续人工修改。
- 实现考试发布和家长签名闭环，严格保证学生/家长仅访问已发布且已绑定的数据。
- 接入 DeepSeek Chat Completions Provider 与 OCR 两阶段流程，明确区分 real/mock/fallback，避免密钥和学生隐私进入前端。
- 优化统计查询并提供趋势、分数段、进步榜、偏科分析及 XLSX/PDF 报告；重接口采用显式筛选、分页和按需加载。
- 建立 SQLite 隔离自动化回归（pytest 31/31）及运行时 smoke 流程，完成本地 MySQL 安全备份/幂等迁移/HTTP 验收，并提供非 root Docker、Compose 与 Kubernetes 部署样例。
