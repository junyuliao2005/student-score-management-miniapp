# 本地开发请求模式

默认配置始终为 `cloud`。只有微信开发者工具的 `develop` 版本会在登录页显示“开发请求模式”，可一键切换“本地 / 云端”；体验版和正式版忽略本地存储覆盖，固定使用云托管。

## 开发者工具

1. 启动本地后端：`cd backend && .\.venv\Scripts\python.exe app.py`。
2. 打开小程序登录页，在“开发请求模式”选择“本地”。
3. 开发者工具勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。
4. 确认 `http://127.0.0.1:5000/api/health` 返回成功后登录。
5. 切回“云端”即可继续体验版链路验证，无需修改 `env.js`。

覆盖值保存在开发工具本地存储键 `dev_request_mode`。`request.js` 和 `upload.js` 每次调用时动态读取，因此切换后立即生效；切到 cloud 时会初始化 `wx.cloud`。

## 真机局域网

手机中的 `127.0.0.1` 指向手机自身，不能访问电脑。真机本地联调需把 `BASE_URL` 设置为电脑局域网地址（如 `http://192.168.x.x:5000`），Flask 监听 `0.0.0.0`，并仅在可信局域网放行 Windows 防火墙端口。完成后恢复本地地址，体验版仍固定走 cloud。

## 安全边界

- 只有 `envVersion=develop` 才接受覆盖值。
- `trial` 和 `release` 强制使用默认 `cloud`，用户不能把体验版切向任意本地服务。
- 开关只控制请求传输方式，不改变登录、权限、上传校验或后端数据范围。
