# 云端文件上传链路说明

## 统一入口

小程序统一使用 `miniprogram/utils/upload.js`：

- `REQUEST_MODE=local`: 使用 `wx.uploadFile` 上传到本地 Flask。
- `REQUEST_MODE=cloud`: 使用 `wx.cloud.uploadFile` 上传到 CloudBase 私有临时目录，获取 `fileID` 和短期临时 URL，再通过 `wx.cloud.callContainer` 通知 Flask 消费文件。

后端处理完成后，小程序调用 `wx.cloud.deleteFile` 清理临时云文件。

## 已接入功能

- 成绩 Excel 预览
- 学生基础信息 Excel 预览
- 试卷图片 OCR 预览

## 安全措施

- 云路径由小程序生成随机文件名，不使用客户端文件名作为服务器路径。
- 后端只接受 `cloud://` fileID 和 HTTPS 临时 URL。
- 临时 URL 主机必须命中 `CLOUD_UPLOAD_ALLOWED_HOST_SUFFIXES` 白名单。
- 禁止 HTTP、重定向和任意 URL 下载，降低 SSRF 风险。
- 下载采用流式大小限制，默认不超过 10MB。
- Excel 校验 ZIP 签名；图片校验真实格式、尺寸和像素。
- 服务端不记录临时签名 URL、Authorization 或文件内容。
- 上传接口有每用户有限频率控制。

## CloudBase 权限要求

云存储必须配置为登录用户只能读写自己的临时目录。建议使用 CloudBase 自定义安全规则，并在真机上验证 `private-uploads/` 的读写隔离。

## 待人工验证

本地环境没有微信开发者工具和 CloudBase 权限，因此云存储上传、临时 URL 下载、处理后删除必须在真实 AppID、真实环境 ID 和真机/体验版中验证。代码完成不等于已通过云端验证。
