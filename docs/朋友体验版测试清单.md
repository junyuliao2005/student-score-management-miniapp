> 真实 K12 数据测试时，不建议只用 `student01 / 123456`。请优先让管理员或开发者用 SQL 找一个初中/高中真实学生账号，导入学生默认密码通常为 `123456`。

查找真实初中学生账号示例：

```sql
SELECT u.user_id, u.username, u.real_name, u.class_name, COUNT(s.score_id) AS score_count
FROM users u
JOIN scores s ON s.student_id = u.user_id AND s.status = 1
WHERE u.class_name LIKE '初%'
GROUP BY u.user_id, u.username, u.real_name, u.class_name
ORDER BY score_count DESC
LIMIT 20;
```

## 学生端我的成绩重点用例

1. 使用真实初中/高中学生账号登录。
2. 进入"我的成绩"。
3. 预期: 页面优先展示成绩总览和各科成绩，筛选区默认折叠。
4. 点击"筛选/搜索"，按"学期 → 考试批次 → 课程号/课程名称"筛选。
5. 课程号/课程名称留空，查询该学期和批次的全部科目成绩。
6. 确认页面显示本次考试成绩总览：总分、平均分、科目数、班级排名、总排名、薄弱科目。
7. 课程号/课程名称输入 `CHN01`，应能查询语文。
8. 课程号/课程名称输入 `语文`，也应能查询语文。

## 教师端重点用例

1. 成绩查询按班级、学期、考试批次筛选。
2. 预期: 结果按班级、学生、考试批次、课程排序，同一学生成绩连续显示。
3. 师生留言发送时观察接收人加载状态。
4. 预期: 加载中、加载失败、空列表都有明确提示；未选择接收人时提示"请先选择接收人"。

## 统计分析重点用例

1. 进入统计分析，默认停留在"成绩概览"，不自动加载所有排名。
2. 总分排名、荣誉榜必须先选择考试批次。
3. 总分排名显示班级排名、年级排名、总排名。
4. 单科排名必须选择考试批次和课程，课程可填 `CHN01` 或 `语文`。
5. 多人同时体验时不要快速重复点击统计按钮；加载时按钮应禁用或显示 loading。

## 成绩发布和家长确认重点用例

1. 教师/管理员进入"考试发布"，创建发布设置。
2. 设置展示项和是否需要家长签名后点击发布。
3. 学生端"我的成绩"只显示已发布成绩；撤回后不再显示。
4. 管理员进入"家长绑定"，绑定家长与学生。
5. 家长登录后只能看到绑定孩子，不能查看未绑定学生。
6. 家长查看孩子已发布成绩，按发布设置展示总分、排名、各科成绩。
7. 需要签名时，家长输入姓名确认。
8. 教师/管理员在"考试发布"中查看确认情况。
