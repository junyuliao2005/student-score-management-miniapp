# 微信开发者工具回归清单

本清单需要真实微信开发者工具和 AppID，由人工执行。当前自动验证只确认 24 个注册页面、96 个页面文件、43 个 JS 和 38 个 JSON 的静态完整性。

## 1. 本地模式

1. 在登录页仅开发版可见的“开发请求模式”中选择“本地”，无需修改 `env.js`。
2. 启动本地 Flask：`cd backend && .\.venv\Scripts\python.exe app.py`。
3. 浏览器确认 `http://127.0.0.1:5000/api/health`。
4. 开发者工具勾选“不校验合法域名”，清缓存并重新编译。
5. 使用用户自有测试凭据依次登录 admin、teacher、student、parent；确认角色首页和菜单不同。
6. 验证学生只看到已发布成绩；教师无绑定时统计为空，管理员授权后仅显示授权班级/课程。
7. 测试预警、留言、考试发布、家长查看和签名确认。

## 2. 文件与报告

1. 教师在成绩录入页选择小型 `.xlsx`，只执行 preview；确认数据正确后再决定是否 confirm。
2. 管理员测试学生 `.xlsx` preview，不使用真实大文件。
3. 选择明确考试批次后导出教师成绩 XLSX，确认 `wx.openDocument` 能打开。
4. 学生/家长对已发布成绩生成 PDF，确认能打开；未发布成绩应被拒绝。
5. 考试发布页导出家长确认表 XLSX。

## 3. OCR 与 AI

1. 进入试卷分析，文本模式和图片模式都能切换。
2. 上传无敏感信息的 jpg/png/webp，观察 uploading -> preview -> analyzing -> done/failed 状态。
3. OCR 预览必须允许修改文字；空文字不能确认。
4. Mock 显示“AI 演示模式”，Fallback 显示“真实模型不可用，已安全降级”，不得显示为 real。
5. 真实 DeepSeek 只在后端 Key 已配置并确认额度后验证；小程序中不得出现 Key。

## 4. 统计懒加载

1. 首次进入统计页只加载概览，不同时请求所有排名/分析接口。
2. 未选考试批次点击总分、荣誉、分布或偏科，应提示而不发起重查询。
3. 进步榜必须选择学期、基准批次和当前批次。
4. 连续点击时按钮 loading/防重复请求有效。

## 5. 完成标准

- Console 无页面未注册、undefined/null/NaN、JS 异常或网络无限重试。
- 每类角色数据范围正确。
- 文件打开、OCR 修改、AI mode 和错误提示均可见。
- 测试完可在开发版开关切回“云端”；体验版和正式版始终强制 cloud，不受开发工具本地存储影响。

## 自动化环境结果

- 发现本机已安装微信开发者工具，但 CLI 需要写入项目目录外的用户数据目录，当前沙箱按安全边界拒绝该写入，故未冒充实际编译或截图成功。
- 已静态验证所有注册页面文件齐全、JS/JSON 合法，并验证 develop 可覆盖 local、trial 强制 cloud。
- 真机页面布局、扫码登录、云存储权限和实际 `wx.openDocument` 仍需人工执行本清单。
