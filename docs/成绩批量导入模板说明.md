# 成绩批量导入模板说明

## 文件格式

- 仅支持 Excel `.xlsx` 文件。
- 第一行必须是表头。
- 从第二行开始填写成绩数据。
- preview 阶段只解析和校验，不写入成绩。
- confirm 阶段只导入合法且不重复的成绩，重复成绩默认跳过。

## 支持表头

| 字段 | 中文表头 | 英文表头 | 是否必填 | 说明 |
|------|----------|----------|----------|------|
| 学号 | 学号 | student_id | 是 | 必须是已启用的学生用户 |
| 课程编号 | 课程编号 | course_id | 是 | 必须是已启用课程 |
| 分数 | 分数 | score | 是 | 数字，范围 0-100 |
| 考试日期 | 考试日期 | exam_date | 是 | 格式 `YYYY-MM-DD` |
| 考试批次 | 考试批次 | exam_batch | 是 | 不能为空，如 `期中`、`期末` |
| 学期 | 学期 | term | 否 | 如填写，会校验是否与课程学期一致 |
| 姓名 | 姓名 | student_name | 否 | 仅用于辅助校验和展示 |
| 课程名称 | 课程名称 | course_name | 否 | 仅用于辅助校验和展示 |

## 校验规则

- 学号必须存在，且用户状态为启用。
- 用户必须是学生角色。
- 课程编号必须存在，且课程状态为启用。
- 分数必须是数字，范围为 0 到 100。
- 考试日期必须是合法日期，格式为 `YYYY-MM-DD`。
- 考试批次不能为空。
- 同一 Excel 文件内不能重复 `学号 + 课程编号 + 考试批次`。
- 数据库中已存在同一 `学号 + 课程编号 + 考试批次` 的有效成绩时，preview 会标记为重复。
- 本版本 confirm 默认跳过重复成绩，不覆盖已有成绩。

## 当前限制

- 仅支持 `.xlsx`。
- 暂不支持 `.docx`。
- 暂不支持覆盖重复成绩。
- 暂不支持自由文本自动识别。
