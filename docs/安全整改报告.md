# 安全整改报告

更新日期：2026-07-11

## 本轮已落实

- 生产环境启动时强制检查 Flask 密钥、JWT 密钥和数据库连接参数；缺失或使用弱默认值时拒绝启动。
- `.env`、本地微信配置、数据库备份、真实数据集、上传文件和运行时缓存已加入 Git/Docker 忽略规则。
- 学生端 `/api/scores/my` 和选项接口仅查询当前登录学生，并严格限制为已发布成绩。
- 家长端仅能读取有效绑定学生的已发布成绩，草稿和撤回发布不会下发。
- Excel 上传校验扩展名、MIME、大小和 ZIP 签名；图片上传使用 Pillow 真实解码并校验格式、尺寸和像素数。
- 上传接口具有按用户和用途区分的进程内频率限制；云端临时 URL 仅允许 HTTPS、443 端口、受信 CloudBase 域名且禁止重定向。
- OCR 预览使用服务端随机 ID、按登录用户隔离、30 分钟过期；确认分析无论成功或失败都会清理预览。
- Excel 导入预览不再缓存明文密码，确认成功后删除预览缓存。
- AI 输入先做长度限制与隐私脱敏；DeepSeek、Mock 和 Fallback 在接口及前端均明确标识。
- DeepSeek 使用独立 `DEEPSEEK_API_KEY`，仅调用 Chat Completions 路径，不读取或输出推理内容。

## 残余风险

- 上传频率限制当前是单进程内存实现；多实例生产部署应迁移到 Redis 或网关限流。
- CloudBase 临时 URL 依赖后端域名允许列表；生产环境应同时启用云存储私有读写安全规则。
- 当前主虚拟环境为 Python 3.14，未安装 RapidOCR/Pillow；真实 OCR 应使用 Python 3.11/3.12 独立环境。
- 教师班级/课程显式绑定已实现并默认拒绝未绑定教师；真实任教关系仍需管理员人工维护。
- 真实 DeepSeek、真实 RapidOCR、微信真机和云托管部署尚未在本轮执行，不能视为已验证。

## 禁止操作

- 不在日志、截图、文档或 Git 中保存 `.env`、JWT、数据库密码和 AI Key。
- 不使用生产数据库执行自动化测试，不以降低权限校验换取测试通过。
- 不允许客户端提供任意下载 URL，不将临时上传目录暴露为静态目录。
