# 云端体验版部署说明

## 后端

后端 Flask 已适配微信云托管：

- 使用 `gunicorn wsgi:app` 启动
- 容器监听 `0.0.0.0:5000`
- 数据库参数从环境变量读取
- `/api/health` 用于健康检查

## 数据库

云端 MySQL 使用环境变量配置：

```env
DB_HOST=
DB_PORT=3306
DB_USER=
DB_PASSWORD=
DB_NAME=student_grade_db
```

不要把数据库密码写入代码或小程序。

## 小程序调用后端

体验版普通 JSON API 使用：

```js
wx.cloud.callContainer
```

配置：

```js
env: 'replace-with-cloud-env-id'
X-WX-SERVICE: 'replace-with-service-name'
```

这样不依赖 `request` 合法域名配置，适合微信体验版测试。

默认 cloud 配置不会被开发版的本地模式覆盖带入体验版：只有 `envVersion=develop` 才读取 `dev_request_mode`，trial/release 始终使用 cloud。

## 为什么不直接使用云托管默认域名

微信云托管默认域名主要用于测试，公众平台配置 request 合法域名时可能提示不能用于正式环境。因此普通 JSON API 改为微信推荐的 `callContainer` 方式。

## 文件上传说明

普通 JSON API 继续使用 `wx.cloud.callContainer`。文件上传已统一由 `miniprogram/utils/upload.js` 处理：

1. `REQUEST_MODE=local` 使用 `wx.uploadFile` 直传本地 Flask。
2. `REQUEST_MODE=cloud` 先使用 `wx.cloud.uploadFile` 写入私有临时目录，再通过 `callContainer` 把 `cloud://` fileID 和短期临时 URL 交给后端消费。
3. 后端只接受受信任 CloudBase HTTPS 域名，拒绝重定向和任意 URL，处理完成后前端调用 `wx.cloud.deleteFile`。

成绩 Excel、学生 Excel 和试卷 OCR 预览均已接入此封装。由于本机没有真实 AppID/CloudBase 权限，云存储安全规则、临时 URL 下载和处理后删除仍需体验版人工验证，不能视为已完成云端实测。
