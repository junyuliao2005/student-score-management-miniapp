# 简历项目写法参考

## 项目名称

学生成绩管理小程序 + AI 学情诊断辅助系统

## 推荐投递方向

小程序开发实习生 / 软件开发实习生 / 前端开发实习生 / 测试实习生 / AI 应用开发实习生

## 简历描述

学生成绩管理小程序 + AI 学情诊断辅助系统｜个人项目 / 课程设计项目｜2025

技术栈：微信小程序、JavaScript、Python、Flask、MySQL、SQLAlchemy、JWT、RBAC、openpyxl、AI 辅助开发

- 基于微信小程序实现登录、首页、成绩录入、成绩查询、我的成绩、统计分析、师生留言、家长端等多个页面，完成基础页面交互与接口联调。
- 使用 Python Flask 搭建后端服务，设计成绩、课程、用户、角色权限、留言、AI 分析、成绩发布等业务模块。
- 实现基于 JWT 的登录认证和简化 RBAC 权限控制，区分学生、教师、管理员、家长等不同角色的功能入口和数据访问范围。
- 实现成绩查询与统计分析功能，支持按班级、学期、考试批次、课程等条件筛选，并展示总分、平均分、班级排名、年级排名、单科排名和荣誉榜。
- 实现 Excel 批量导入预览与确认流程，支持学生基础信息和成绩数据导入，能够识别错误行、重复行并避免直接写库导致的数据污染。
- 编写 README、API 接口清单、测试说明、答辩演示路线和朋友体验版测试清单，完成项目部署、测试和演示材料整理。
- 在 AI 工具辅助下完成需求拆解、代码理解、问题排查和功能迭代，提升了项目开发效率和工程落地能力。

## 面试回答：这个项目是不是你自己做的？

可以这样回答：

这个项目是我的课程设计 / 个人实践项目，主要由我推进完成。开发过程中我使用了 AI 工具辅助需求拆解、代码理解、问题排查和文档整理，但功能联调、运行测试、页面调整和最终项目整理是我自己完成的。通过这个项目，我主要学习了微信小程序开发、Flask 后端接口、MySQL 数据表设计、JWT 权限控制和 Excel 导入流程。
