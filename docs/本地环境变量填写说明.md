# 本地环境变量填写说明

真实值只填写在 `backend/.env`，该文件已被 Git 和 Docker 排除。不要把值写入 `.env.example`、Markdown、小程序或 Git。

## 本地 Flask 与 MySQL

```env
FLASK_ENV=development
SECRET_KEY=填写本地随机长字符串
JWT_SECRET_KEY=填写另一条不同的随机长字符串
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=填写本地数据库用户
DB_PASSWORD=填写本地数据库密码
DB_NAME=student_grade_db
```

迁移脚本只允许在 `DB_HOST=127.0.0.1|localhost|::1` 且先完成备份后执行。已有数据库严禁运行 `init_db.py`。

## DeepSeek V4 Pro

```env
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=在此填写真实Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_CHAT_ENDPOINT=/chat/completions
DEEPSEEK_MODEL=deepseek-v4-pro
DEEPSEEK_THINKING_ENABLED=true
DEEPSEEK_REASONING_EFFORT=max
AI_TIMEOUT_SECONDS=90
AI_MAX_RETRIES=2
AI_FALLBACK_ENABLED=true
```

- DeepSeek Key 只使用 `DEEPSEEK_API_KEY`。
- 不要设置或复用 `OPENAI_API_KEY`。
- 实现只请求 `/chat/completions`，不请求 `/responses`。
- 无 Key 时保持 `AI_PROVIDER=mock`，真实连接脚本应显示 `SKIPPED`。

## OCR

```env
OCR_PROVIDER=mock
OCR_FALLBACK_ENABLED=true
OCR_PREVIEW_DIR=
```

真实本地 OCR 安装完成后才改为 `OCR_PROVIDER=local`。通过 `OCR_PYTHON` 或 `setup_ocr_env.ps1 -PythonPath` 指向 Python 3.11/3.12，不要在 Python 3.14 主环境强装 OCR 重依赖。

## 小程序请求模式

默认配置保持 cloud。微信开发者工具 develop 版本在登录页显示“开发请求模式”，可一键切换本地/云端；trial/release 忽略本地覆盖并强制 cloud。详见 `docs/本地开发请求模式.md`。

## 本轮安全检查

只读取了变量名和是否为空，不输出值。当前 `.env` 存在；DB 主机判定为本地，数据库连接字段齐全；`AI_PROVIDER=deepseek`，DeepSeek Key 非空，`OPENAI_API_KEY` 变量不存在。单次有界连接因当前网络限制失败，没有打印 Key 或继续消耗调用。
