# 部署与运行说明

## 1. 环境要求

- **Python**: 3.9+
- **MySQL**: 8.0+
- **微信开发者工具**: 最新稳定版
- **操作系统**: Windows 10/11, macOS, Linux

---

## 2. 后端部署

### 2.1 创建虚拟环境

```bash
cd backend
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate
```

### 2.2 安装依赖

```bash
pip install -r requirements.txt
```

依赖列表：
- Flask 2.3.3
- Flask-SQLAlchemy 3.1.1
- Flask-Cors 4.0.0
- PyMySQL 1.1.0
- PyJWT 2.8.0
- Werkzeug 2.3.7
- requests 2.31.0
- python-dotenv 1.0.1

### 2.3 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env` 文件：

```env
# 数据库配置
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=student_grade_db

# JWT 配置
JWT_SECRET_KEY=your-secret-key

# AI 配置（默认 mock 模式，无需外部 API 即可演示）
AI_PROVIDER=mock
AI_API_KEY=
AI_MOCK_ENABLED=true
```

### 2.3.1 接入真实 AI API（可选）

如需使用真实 AI 分析能力，在 `.env` 中修改以下配置：

```env
AI_PROVIDER=openai_compatible
AI_API_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_API_KEY=你的API密钥
AI_MODEL=qwen-turbo
AI_MOCK_ENABLED=false
```

支持的服务商（OpenAI 兼容接口）：

| 服务商 | AI_API_BASE_URL | AI_MODEL 示例 |
|--------|----------------|---------------|
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-turbo` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |

**说明：**
- 小程序前端不直接保存 API Key，所有 AI 请求通过 Flask 后端代理
- 如果 `AI_MOCK_ENABLED=true`，真实 API 调用失败时自动降级到 Mock 模式
- 如果 `AI_MOCK_ENABLED=false`，API 调用失败会返回错误

### 2.4 初始化 MySQL 数据库

**方式 A（推荐）：使用 Python 初始化脚本**

```bash
cd backend
python scripts/init_db.py
python scripts/seed_demo.py
```

`init_db.py` 会自动建表、初始化 RBAC 角色权限、系统配置和演示账号。`seed_demo.py` 填充 20 个学生、5 门课程、100 条成绩。

**方式 B：手动执行 SQL**

```bash
# schema.sql 内部已包含 CREATE DATABASE IF NOT EXISTS，首次执行无需手动建库
mysql -u root -p < sql/schema.sql
mysql -u root -p < sql/seed_config.sql
```

> 注意：`schema.sql` 包含 `CREATE DATABASE` 和 `USE student_grade_db`，因此 mysql 命令后不要提前指定数据库名。

演示数据包含：
- 1 个管理员、2 个教师、20 个学生（2 个班级）
- 5 门课程：语文、数学、英语、物理、计算机基础
- 100 条成绩记录，覆盖：高分、中等、低分、偏科、同分、边界值（59.99/60/89.99/90/100）
- 自动触发统计刷新（总分/均分/排名/等级/评语）

### 2.6 启动 Flask

```bash
python app.py
```

后端默认运行在 `http://127.0.0.1:5000`

### 2.7 验证后端

浏览器访问: `http://127.0.0.1:5000/api/health`

预期返回:
```json
{"code": 0, "data": {"status": "ok", "version": "1.0.0"}, "message": "success"}
```

## 3. 小程序部署

### 3.1 导入项目

1. 打开**微信开发者工具**
2. 点击**导入项目**
3. 项目目录选择: `E:\mimo 小米，学生成绩小程序\miniprogram`
4. AppID: 选择**测试号**或点击"无 AppID"
5. 点击**确定**

### 3.2 配置后端地址

编辑 `miniprogram/env.js`：

```javascript
const env = {
  BASE_URL: 'http://127.0.0.1:5000',
  AI_ENABLED: false,
};
module.exports = env;
```

### 3.3 本地调试设置

在微信开发者工具中：
1. 点击右上角**详情**
2. 选择**本地设置**
3. 勾选: **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

### 3.4 编译运行

点击**编译**按钮，小程序加载后可进行登录和功能测试。

## 4. 常见报错处理

### 4.1 pip install 失败

```
ERROR: Could not find a version that satisfies the requirement
```

**解决**: 升级 pip
```bash
python -m pip install --upgrade pip
```

### 4.2 MySQL 连接失败

```
pymysql.err.OperationalError: (2003, "Can't connect to MySQL server")
```

**解决**:
- 检查 MySQL 服务是否启动
- 检查 .env 中 DB_HOST/DB_PORT/DB_USER/DB_PASSWORD 是否正确
- 检查防火墙是否放行 3306 端口

### 4.3 表不存在

```
Table 'student_grade_db.xxx' doesn't exist
```

**解决**: 执行建表脚本（推荐使用 Python 初始化脚本）
```bash
# 方式 A（推荐）
cd backend
python scripts/init_db.py

# 方式 B：手动执行 SQL
# schema.sql 内部包含 CREATE DATABASE 和 USE，首次执行不要提前指定数据库名
cd backend
mysql -u root -p < sql/schema.sql
mysql -u root -p < sql/seed_config.sql
```

### 4.4 小程序请求失败

```
request:fail url not in domain list
```

**解决**: 在微信开发者工具中勾选"不校验合法域名"

### 4.5 401 Unauthorized

```
{"code": 40001, "message": "Token 已过期"}
```

**解决**: 重新登录获取新 Token

### 4.6 403 Permission Denied

```
{"code": 30001, "message": "权限不足"}
```

**解决**: 检查当前用户角色是否有对应权限

### 4.7 真机调试连不上后端

**原因**: 手机无法访问 `127.0.0.1`

**解决**:
1. 将 `env.js` 中 `BASE_URL` 改为电脑的局域网 IP（如 `http://192.168.1.100:5000`）
2. 确保手机和电脑在同一 WiFi 网络
3. 在微信开发者工具中使用"真机调试"模式

### 4.8 没有 AppID

**解决**: 在微信开发者工具中选择"测试号"或"无 AppID"，不影响本地调试
