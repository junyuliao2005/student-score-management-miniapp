# 密钥轮换操作清单

## 需要轮换的密钥

- `SECRET_KEY`
- `JWT_SECRET_KEY`
- `DB_PASSWORD`
- `DEEPSEEK_API_KEY`（已配置真实模型时）
- `AI_API_KEY` / `AI_VISION_API_KEY`（启用相应 Provider 时）

## 安全步骤

1. 在密码管理器中生成至少 32 字节的随机 Flask/JWT 密钥，不在聊天或提交记录中展示。
2. 在数据库控制台创建或轮换最小权限应用账号密码；不要使用文档示例值。
3. 在微信云托管环境变量中更新密钥，不写入 Dockerfile、源码或小程序端。
4. 先部署到测试环境，验证 `/api/health`、登录和一条只读业务请求。
5. 切换生产实例并观察认证失败率、数据库连接和 AI 错误分类日志。
6. JWT 密钥轮换后旧 Token 会失效，应通知体验用户重新登录。
7. 确认新密钥生效后，在原提供方撤销旧密钥。
8. 检查日志和 Git 暂存区不包含密钥；如曾进入 Git 历史，应在代码托管平台按泄露事件处理并立即轮换。

