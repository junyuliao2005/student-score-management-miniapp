# 学生成绩管理小程序 + AI 学情诊断辅助系统

## 项目定位

面向小学、初中、高中的微信小程序成绩管理系统。项目覆盖管理员、教师、学生、家长四类角色，后端采用 Flask、SQLAlchemy、MySQL，支持微信云托管和本地开发双请求模式。

## 核心能力

- 成绩单条录入、Excel preview/confirm、智能 K12 Excel 宽表/长表/混合表适配。
- 导入批次原子账本、敏感快照脱敏、人工修改保护和非破坏性安全撤销。
- 考试发布、学生 published 可见性、家长绑定、签名确认和确认表导出。
- 教师班级/课程双重绑定，成绩、统计、预警、AI、发布、留言全链路范围校验。
- 总分/单科排名、趋势、分数段、进步榜、偏科分析、预警与多种报告。
- DeepSeek Provider、Mock/Fallback 明示、OCR 预览人工修正、AI 历史与反馈。
- local `wx.request` / cloud `wx.cloud.callContainer` 统一普通请求和文件上传抽象。

## 工程质量

- SQLite 隔离 pytest 31/31，运行时回归 19/19，统计纯函数 31/31；另完成本地 MySQL 安全备份、幂等迁移和真实 HTTP 只读验收。
- 生产密钥 fail-closed、上传真实解码/签名/限流、CloudBase URL allowlist 和无重定向。
- 非 root Docker、健康检查、Compose 开发环境和 Kubernetes 安全上下文示例。

## 可演示亮点

用同一条成绩串联“教师导入 -> 管理员追踪 -> 考试发布 -> 学生查看 -> 家长确认 -> 统计分析 -> AI 建议”，同时展示越权被拒绝和 Mock/真实结果不混淆。
