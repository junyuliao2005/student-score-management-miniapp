# 教师范围与四角色验收说明

## 教师绑定原则

教师范围由 `teacher_class_bindings` 与 `teacher_course_bindings` 同时约束。迁移后没有绑定的教师默认看不到全校数据；系统不会猜测任教关系，也不会自动授予全校权限。

管理员应在“小程序首页 -> 教师任教范围”中选择教师，明确勾选班级和课程后保存。也可调用 `PUT /api/admin/teacher-bindings/<teacher_id>`，请求体只提交人工确认的 `class_names` 与 `course_ids`。

## 四角色验收

1. 管理员：教师范围、导入批次、考试发布、家长确认、审计日志可见；不显示“我的成绩”。
2. 教师：未绑定时成绩、统计、发布和班级 AI 返回空范围或权限提示；绑定后只能访问班级与课程交集。
3. 学生：只看当前登录学生本人且处于 published 发布范围内的成绩、趋势、AI 建议和 PDF。
4. 家长：只看有效绑定孩子的 published 成绩，可签名确认和导出 PDF，修改 student_id 不得越权。

真实本地数据库当前教师绑定为空，已验证默认拒绝。要验证“绑定后允许”，请由管理员选择一个测试教师及明确班级/课程；不要用脚本自动把所有教师绑定到全校。
