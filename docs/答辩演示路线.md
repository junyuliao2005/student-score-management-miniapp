# 答辩演示路线

## 管理员演示路线

1. 登录 `admin01 / 123456`
2. 查看用户管理，说明真实 K12 学生数据已导入
3. 查看课程管理，展示 K12 课程
4. 进入家长绑定，展示家长与学生绑定关系
5. 进入考试发布，展示发布/撤回和家长确认情况
6. 查看系统配置，演示学生端总分、排名、统计、预警显示开关
7. 查看日志或配置页面，说明具备基础运维能力

## 教师演示路线

1. 登录 `teacher01 / 123456`
2. 进入成绩查询，按班级、学期、批次筛选，说明结果按学生分组排序
3. 进入统计分析，展示"成绩概览 / 总分排名 / 单科排名 / 荣誉榜"分区
4. 选择考试批次查看总分排名，说明班级排名、年级排名、总排名
5. 选择课程查看单科排名，说明课程号和课程名称都可查询
6. 进入预警名单，展示低分/偏科预警
7. 进入 AI 班级分析，选择真实班级生成 mock 学情分析
8. 进入师生留言，展示教师可给学生留言以及接收人加载提示
9. 进入考试发布，创建发布设置并发布成绩，说明发布状态只影响学生/家长端展示

## 学生演示路线

1. 优先登录一个真实初中/高中学生账号，默认密码通常为 `123456`；不要只依赖 `student01 / 123456`
2. 进入"我的成绩"
3. 说明页面优先展示成绩，筛选/搜索默认折叠
4. 展开筛选，选择学期和考试批次，课程号/课程名称留空，展示本次考试全部科目成绩
5. 查看总分、平均分、科目数、班级排名、总排名
6. 查看各科明细和薄弱科目提示
7. 在课程号/课程名称中分别输入 `CHN01` 和 `语文`，说明课程编号和课程名称都可查询
8. 进入师生留言，查看或回复留言

## 家长演示路线

1. 登录 `parent01 / 123456`
2. 查看已绑定孩子列表
3. 点击孩子进入成绩页
4. 查看已发布考试成绩，说明未发布/已撤回成绩不可见
5. 查看发布设置控制的展示项：总分、排名、各科成绩
6. 如需要签名，输入家长姓名确认
7. 回到教师/管理员端查看确认情况

查找真实初中学生账号的只读 SQL：

```sql
SELECT u.user_id, u.username, u.real_name, u.class_name, COUNT(s.score_id) AS score_count
FROM users u
JOIN scores s ON s.student_id = u.user_id AND s.status = 1
WHERE u.class_name LIKE '初%'
GROUP BY u.user_id, u.username, u.real_name, u.class_name
ORDER BY score_count DESC
LIMIT 20;
```

## 真实 K12 数据导入亮点

- 支持学生基础信息 Excel 导入
- 支持成绩 Excel 导入
- 支持 K12 真实班级、课程、成绩进入统计和 AI 分析

## 智能 Excel 适配器亮点

- 规则识别版，不调用 AI
- 自动识别学生表、成绩长表、成绩宽表、混合表
- 自动生成标准导入模板
- K12 范围过滤，忽略大学教务数据

## 云端体验版部署亮点

- Flask 后端部署到微信云托管
- 数据库迁移到云端 MySQL
- 小程序普通 JSON API 使用 `wx.cloud.callContainer`
- 体验版无需配置 request 合法域名

## AI 学情分析说明

- 当前默认 mock，稳定可演示
- 后续可通过后端环境变量切换到 OpenAI-compatible API
- API Key 不放在小程序端

## 总分排名和荣誉榜亮点

- 按学期、考试批次、班级实时聚合总分
- 支持竞赛排名法：同分同名次
- 支持班级排名、年级排名和总排名
- 支持单科排名，课程可按编号或名称查询
- 统计分析分为概览、总分排名、单科排名和荣誉榜，避免一次性触发重接口
- 荣誉榜展示总分前 10、单科第一和优秀学生

## 成绩发布与家校确认亮点

- 教师/管理员可创建考试发布设置，控制发布范围和展示字段
- 支持发布、撤回，后台统计不受发布状态影响
- 学生端和家长端只展示已发布成绩
- 家长端通过绑定关系查看孩子成绩，不能越权查看其他学生
- 支持文本签名确认，教师/管理员可查看确认进度
- 当前 MVP 暂未做定时发布、手写签名图片、复杂通知和教师任教范围精细控制
