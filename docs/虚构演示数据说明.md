# 虚构演示数据说明

公开版的演示数据由 `backend/scripts/seed_demo.py` 生成，仅用于新建的本地开发数据库。脚本中的 `A001/T001/T002/S001-S020`、教师和学生姓名、两个演示班级、课程与成绩均为虚构测试数据，不来源于真实学校。

执行该脚本会写数据库，只允许在全新、可丢弃的开发数据库中人工运行。已有真实数据库不得运行 `init_db.py` 或演示数据脚本；升级已有库只执行文档列出的非破坏性幂等迁移。

公开截图、测试报告和问题复现必须使用这些虚构数据，不得使用真实学生姓名、学号、成绩、家长信息、Token、trace 日志或云环境标识。
