### 2.7 真实 K12 学生账号查询

不建议只使用 `student01 / 123456` 或赵一测试学生端成绩，因为演示账号数据量可能较少。真实 K12 数据导入后，可用只读 SQL 查找初中/高中学生账号：

```sql
SELECT u.user_id, u.username, u.real_name, u.class_name, COUNT(s.score_id) AS score_count
FROM users u
JOIN scores s ON s.student_id = u.user_id AND s.status = 1
WHERE u.class_name LIKE '初%'
GROUP BY u.user_id, u.username, u.real_name, u.class_name
ORDER BY score_count DESC
LIMIT 20;
```

查看某个真实学生的学期、批次和课程：

```sql
SELECT s.student_id, u.username, u.real_name, u.class_name,
       c.term, s.exam_batch, s.course_id, c.course_name, s.score
FROM scores s
LEFT JOIN users u ON u.user_id = s.student_id
LEFT JOIN courses c ON c.course_id = s.course_id
WHERE s.student_id = '替换为真实学生ID'
  AND s.status = 1
ORDER BY c.term, s.exam_batch, s.course_id;
```

导入学生默认密码通常为 `123456`。

## 13. 隐私保护与越权访问测试

本节用于答辩前验证"学生成绩不会被越权查看"。测试时不要清空数据库，不要重导数据。

### 13.1 学生端边界

1. 使用学生 A 登录，只访问 `/api/scores/my`，应只返回当前登录学生自己的成绩。
2. 在请求参数中手动增加 `student_id=其他学生ID`，后端应忽略该参数，仍只返回当前登录学生成绩。
3. 学生访问 `/api/scores`、`/api/stats/overview`、`/api/scores/import/preview` 应失败，返回权限不足或未授权。
4. 学生端如果没有已发布成绩，应显示友好提示，不应暴露数据库错误信息。

### 13.2 家长端边界

1. 使用 `parent01` 登录，`/api/parents/my-children` 只能返回已绑定孩子。
2. 访问 `/api/parents/children/<已绑定student_id>/published-scores` 应成功。
3. 将 URL 中的 `student_id` 改为未绑定学生，应失败，不能返回该学生成绩。
4. 家长只能看到 `published` 成绩；`draft` 和 `withdrawn` 发布记录不应返回。
5. 家长签名确认只能确认自己绑定孩子的发布记录，不能确认未绑定学生。
6. 家长访问教师成绩查询、成绩导入、统计分析接口应失败。

### 13.3 教师与管理员边界

1. 教师/管理员可访问成绩查询、统计分析、预警、考试发布管理等授权页面。
2. 教师/管理员接口不应返回密码哈希、token、API key 等敏感字段。
3. 教师必须具有有效班级和课程绑定；无绑定默认不能查看或写入全校成绩。

### 13.4 Token 与登录安全

1. 未登录访问成绩接口应失败。
2. 不带 token 访问 `/api/scores/my`、`/api/parents/my-children` 应失败。
3. 使用伪造 token 或过期 token 应失败。
4. 登录成功应写入 `auth.login` 审计日志。
5. 登录失败应写入 `auth.login_failed` 审计日志，不能记录明文密码。
