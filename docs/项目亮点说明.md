# 项目亮点说明

## 1. 前后端分离架构

- 微信小程序原生前端 + Flask REST API 后端
- 清晰的三层架构：表现层 → 业务逻辑层 → 数据访问层
- 前后端通过 JSON 接口通信，可独立开发和测试

## 2. RESTful API 设计

- 22 个接口覆盖 7 个功能模块
- 统一响应格式：`{code, message, data, trace_id}`
- 标准 HTTP 方法语义：GET 查询、POST 创建、PUT 修改、DELETE 删除
- 统一错误码体系（20001-60003）

## 3. JWT + RBAC 权限控制

- JWT (PyJWT, HS256) 无状态认证，2 小时过期
- 简化版 RBAC 五表模型：users → user_role → roles → role_permission → permissions
- 19 个细粒度权限点，覆盖所有操作
- 中间件级权限校验，业务代码无侵入

## 4. MySQL 关系表设计

- 11 张表，覆盖用户、角色、课程、成绩、配置、日志、AI 分析等
- 使用 InnoDB 引擎，支持事务和外键
- 成绩表设计了派生字段（total_score, avg_score, rank_no, level_tag, comment_text）
- 唯一约束防止重复录入

## 5. 统一响应和错误处理

- 中间件统一捕获异常，返回标准 JSON
- BusinessError 自定义异常类，携带错误码和 HTTP 状态码映射
- 全局 404/405/500 处理
- trace_id 贯穿请求全链路，便于问题追踪

## 6. 统计排名算法

- 竞赛排名：同分同名次，下一个名次跳过（1,1,3,4）
- 支持 None 分数（不参与排名）
- 成绩写入后同步刷新统计，保证数据一致性
- 可配置的等级分段区间（通过 sys_config 表）

## 7. 低分/偏科预警

- 低分预警：单科成绩低于阈值（默认 60，可配置）
- 偏科预警：最高分与最低分差距超过阈值（默认 20，可配置）
- 预警数据按需计算，不持久化，成绩更新后自动同步
- 支持按学期、班级、预警类型筛选

## 8. AI 学情分析

- **策略模式**：ai_service → ai_provider（真实 API）/ ai_mock_service（本地规则）
- **默认 mock 模式**：无需 API Key 即可完整演示
- **基于真实数据**：mock 分析基于实际成绩数据生成，不是固定文本
- **输入安全**：text_sanitizer 清洗危险提示词，限制输入长度
- **隐私保护**：学生只能查看自己的分析，教师只能查看相关班级

## 9. AI 试卷考点分析

- 支持粘贴试卷文本进行考点分析
- Mock 模式通过关键词和文本长度规则模拟分析
- 支持结合成绩和试卷生成个性化复习建议
- 分析结果持久化到 exam_paper 和 ai_analysis 表

## 10. Mock 模式保证可演示

- AI 模块默认 mock，零外部依赖
- Mock 基于真实成绩数据动态生成分析
- 结果明确标注"演示模式"
- 预留 OpenAI-compatible 接口结构，配置 API Key 即可切换

## 11. 工程化文档和测试

- 完整的 README.md，包含启动指南、API 文档、FAQ
- 纯函数验证脚本（verify_stats.py），31 项测试全部通过
- 演示数据填充脚本（seed_demo.py），含 10 学生、3 课程、30 成绩
- 数据库初始化脚本（init_db.py），一键创建表和初始数据
- 答辩演示流程文档，8-10 分钟完整演示

## 12. 代码质量

- 清晰的模块划分和目录结构
- 统一的代码风格和命名规范
- 关键函数有文档字符串
- 错误处理覆盖所有关键路径
- 审计日志记录所有重要操作
