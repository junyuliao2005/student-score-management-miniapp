# 学生基础信息批量导入模板说明

## 文件格式

- 仅支持 `.xlsx`
- 第一行必须是表头
- 从第二行开始填写学生数据
- 空行会自动跳过

## 必填字段

| 中文表头 | 英文字段 | 示例 | 说明 |
|----------|----------|------|------|
| 学号 | student_id | S101 | 写入用户 ID，不可重复 |
| 姓名 | real_name / student_name | 张三 | 写入真实姓名 |
| 班级 | class_name | 2025级1班 | 写入班级名称 |

## 可选字段

| 中文表头 | 英文字段 | 示例 | 说明 |
|----------|----------|------|------|
| 用户名 | username | S101 | 为空时默认使用学号 |
| 年级 | grade | 2025级 | MVP 中仅预览展示 |
| 学校 | school_name | 第一中学 | MVP 中仅预览展示 |
| 性别 | gender | 男 | MVP 中仅预览展示 |
| 手机号 | phone | 13800000000 | MVP 中仅预览展示 |
| 初始密码 | password | 123456 | 为空时默认 `123456` |

## 导入规则

- 导入用户固定分配 `student` 角色。
- 用户状态默认启用。
- `preview` 阶段只解析和校验，不写入数据库。
- `confirm` 阶段只导入 `status=valid` 的行。
- 数据库已有学号时标记为 `duplicate`，确认导入时跳过。
- 数据库已有用户名且不属于该行学号时标记为错误。
- 同一个 Excel 内重复学号或重复用户名会标记为错误。
- 不覆盖已有学生，不修改已有学生信息。
