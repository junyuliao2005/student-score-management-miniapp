# 真机测试清单

## 基础与网络

- [ ] 使用真实 AppID，手机与开发环境网络符合当前 local/cloud 模式。
- [ ] 冷启动、切后台、重新进入、Token 过期均有合理行为。
- [ ] 多账号同时登录不互相清除 Token；统计加载不阻塞另一账号普通请求。

## 四角色

- [ ] 管理员：用户、课程、教师范围、家长绑定、考试发布、导入批次、日志。
- [ ] 教师：授权范围成绩、统计、预警、留言、AI、Excel preview/confirm。
- [ ] 学生：仅本人 published 成绩、趋势、PDF、留言；不能访问教师页面。
- [ ] 家长：仅有效绑定孩子的 published 成绩、PDF、签名确认；不能修改 student_id 越权。

## 输入、选择与页面布局

- [ ] 学号、课程、学期、批次、班级等字段均能手动输入和 picker 回填。
- [ ] 输入框不被压扁，按钮不重叠，长班级名/考试批次不溢出。
- [ ] 无选项时提示“暂无可选项，可手动输入”。
- [ ] 所有列表空态、失败态、重试态可见，不出现白屏或 undefined/null/NaN。

## 文件上传与导出

- [ ] 小型成绩 XLSX preview 和 confirm。
- [ ] 小型学生 XLSX preview 和 confirm。
- [ ] 图片 jpg/jpeg/png/webp 上传、进度、取消、失败重试。
- [ ] 教师 XLSX、家长确认 XLSX、学生/家长 PDF 能保存并打开。

## OCR 与 AI

- [ ] OCR 文字可编辑，确认后才触发分析，取消不写正式分析。
- [ ] Mock、Fallback、Real 三种 mode 文案明确。
- [ ] provider/model/trace_id/generated_at/usage 展示或响应存在。
- [ ] 不展示 reasoning_content、Key、服务器文件路径或完整敏感 Prompt。

## 签名与发布

- [ ] draft 不可见；published 可见；withdrawn 立即不可见。
- [ ] 家长签名只针对绑定孩子，重复确认和未绑定访问有明确提示。
- [ ] 发布列表已确认/待确认数量正确，确认表可导出。

## 测试记录

记录手机型号、系统版本、微信版本、基础库版本、网络模式、账号角色、复现步骤、截图和 trace_id。测试数据使用 `TEST_` 前缀并按文档人工清理，不对正式数据执行撤销或删除。
